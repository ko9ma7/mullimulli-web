멀리멀리 v3.9 - 온라인 계정 자동 연결

이 버전은 Worker/D1만 설정하고 끝나지 않습니다.
SETUP_ONLINE.cmd가 최신 프로젝트(.github/workflows/deploy.yml 포함)를
ko9ma7/mullimulli-web 저장소에 자동 업로드한 뒤 GitHub Pages 배포까지 기다립니다.

1. ZIP을 새 폴더에 압축 해제
   예: C:\worker\mullimulli-web-v3.9
2. SETUP_ONLINE.cmd 더블클릭
3. Cloudflare/GitHub 브라우저 승인이 뜨면 승인
4. 끝에 아래 문구가 나올 때까지 창을 닫지 않기
   - GitHub Pages 배포 성공
   - GitHub Pages가 Worker API를 사용하는 온라인 모드로 전환되었습니다.
   - Setup finished successfully.

사이트에서 확인할 것
- 상단에 "● 온라인" 표시
- 친구 화면에 "● 온라인 계정 연결됨" 표시
- "로컬 데모"가 보이면 아직 온라인 배포가 반영되지 않은 상태

중요: 이전 로컬 데모에서 만든 @아이디는 Cloudflare D1 계정이 아닙니다.
온라인 모드로 바뀐 뒤 각 브라우저/휴대폰에서 한 번씩 다시 가입해야 서로 검색됩니다.

편지 버튼이 켜지는 조건
1. 두 계정이 온라인 서버에 가입되어 있음
2. 서로 친구로 추가되어 있음
3. 보내는 사람과 받는 사람 모두 "위치 업데이트"를 한 번 실행함
4. 거리 확인이 성공함

v3.9은 상대가 위치 업데이트 "시각"을 비공개로 해도 서버에서 거리 계산이 되면
편지를 보낼 수 있도록 수정했습니다. 보내기 화면의 "거리/위치 다시 확인" 버튼으로
상대가 방금 위치를 갱신한 상태를 즉시 다시 확인할 수 있습니다.
