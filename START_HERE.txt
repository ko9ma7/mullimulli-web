멀리멀리 v4.0 - 가장 쉬운 업데이트/배포 방법

중요: GitHub 저장소에 docs 파일이 보인다고 해서 GitHub Pages가 새 버전으로 배포된 것은 아닙니다.
특히 .github/workflows/deploy.yml이 저장소에 없으면 GitHub Actions 방식 Pages는 새 배포가 실행되지 않습니다.

이미 온라인 계정(Cloudflare D1/Worker)을 연결한 경우
1. ZIP을 새 폴더에 압축 해제
2. PUBLISH_UPDATE.cmd 더블클릭
3. 기존 Cloudflare/D1/Worker를 재사용하고 최신 프로젝트 + .github/workflows/deploy.yml을 GitHub에 올립니다.
4. GitHub Pages Actions가 끝날 때까지 기다립니다.
5. 자동으로 열린 사이트를 확인합니다.

처음 온라인 계정을 연결하는 경우
- SETUP_ONLINE.cmd 더블클릭
- Cloudflare/GitHub 브라우저 승인이 뜰 때만 승인
