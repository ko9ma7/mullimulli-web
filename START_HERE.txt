멀리멀리 v4.4

이번 버전은 가입/로그인 500 오류를 수정한 서버 호환 패치입니다.

원인: v4.3 Worker가 PBKDF2-SHA-256을 210,000회 실행했지만 Cloudflare workerd는 PBKDF2 반복 횟수를 최대 100,000회로 제한합니다. 그래서 사용자 DB INSERT 전에 가입 요청이 실패했습니다.

실행 방법
1. 이 ZIP을 새 폴더에 압축 해제
2. UPDATE_V4_4.cmd 더블클릭
3. Cloudflare/GitHub 승인이 뜨면 승인
4. 마지막에 "실제 가입 + 로그인 API 테스트 성공"과 SUCCESS가 나오는지 확인
5. 사이트 Ctrl+F5 후 가입/로그인

기존 D1을 삭제하거나 새로 만들 필요가 없습니다.
