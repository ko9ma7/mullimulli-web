# v4.0 디자인 검수 기록

기준 시안: 사용자 제공 4번째 이미지 (`design/concept-v3.8-desktop.png` 계열의 승인 방향)

- 상단 내비게이션: 중앙 메뉴 + 우측 프로필 구조 유지.
- Hero: 큰 카피는 유지하되 높이를 줄여 보내기 UI가 첫 화면에 더 많이 노출되도록 수정.
- 데스크톱 컬럼: Hero/보내기/여정을 왼쪽 주 영역에, 프로필/친구/통계를 오른쪽 고정 열에 배치.
- 보내기: 받는 사람/메시지 작성은 왼쪽, 전달자 6개 추천은 오른쪽에 동시 노출.
- 전달자: 전체 50개는 기본 숨김, 확장 버튼 사용.
- 배송 요약: 전달자/성공률/거리, D-Day, 남은 시간, 도착 예정 년월일·요일·시간, 발송 버튼을 하나의 요약 바에 배치.
- 여정 요약: 데스크톱 3열 카드, 진행률과 D-Day를 함께 표시.
- 여정 상세: 출발 일시/총 소요시간/도착 예정/D-Day/남은 시간을 명확히 분리.
- 모바일: 390px에서 가로 오버플로 0px 확인. 한 열 배치 및 하단 내비게이션 유지.

의도적 차이: 기준 시안의 모든 전달자 일러스트를 개별 래스터 캐릭터로 만들지 않고 현재 50종 카탈로그의 이모지/아이콘 표현을 유지했습니다. 기능 데이터와 50종 확장성을 우선한 결정입니다.
